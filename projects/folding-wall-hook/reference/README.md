# Reference models (local only — not committed)

Drop the original **Folding Wall Hook** files here (the `.zip` from the
Printables "Files" section, or the extracted `.stl` files):

<https://www.printables.com/model/1616074-folding-wall-hook>

Everything in this folder except this README is **git-ignored**, so VC Design's
files are never committed or redistributed. They're used only locally as a
dimensional reference — Demiourgos `measure` on each STL to match the recreation
to the real part.

Once the files are here, ask Demiourgos to measure them and compare.
